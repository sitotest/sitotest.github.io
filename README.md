# Centro Veterinario Ferreri — Sito Web

Sito web statico, responsive e animato per il **Centro Medico Veterinario Ferreri** (Catania), specializzato in medicina interna e oncologia veterinaria.

Redesign completo del sito storico: stessa struttura di contenuti e pagine, nuova grafica pulita in stile clinico (bianco / verde / azzurro), completamente responsive per smartphone e tablet, con animazioni allo scroll e galleria fotografica con popup.

## 🔗 Demo

Apri semplicemente `index.html` in un browser, oppure pubblica la cartella su un qualsiasi hosting statico (GitHub Pages, Netlify, Vercel...).
